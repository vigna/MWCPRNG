Code for the Search of Candidate Multipliers
============================================

The code in this directory generates candidate multipliers for MWC and GMWC
generators and computes their spectral figures of merit. It uses
[NTL](https://www.shoup.net/ntl/) and
[LatticeTester](https://github.com/umontreal-simul/latticetester).

- `searchMWC.cpp` prints, for MWC generators with base *b* and lag *k*, the
  multipliers *a* such that the modulus *m* = *a* *bᵏ* − 1 of the associated
  multiplicative congruential generator and (*m* − 1) / 2 are both prime,
  together with *m*. The configuration is chosen at compile time with
  `-DBITS_<base bits>_<state bits>`: `BITS_32_64` and `BITS_32_128`
  enumerate the multipliers in the interval given on the command line, whereas
  `BITS_64_128`, `BITS_64_192`, and `BITS_64_256` generate random multipliers
  with the upper eight bits set, using a `xoshiro256++` generator seeded on
  the command line:

      g++ -O3 -DBITS_64_128 searchMWC.cpp -o searchMWC -lntl -lgmp

  These are the configurations used in the paper. The remaining ones take no
  argument and enumerate a fixed interval of multipliers: `BITS_8_32` and
  `BITS_16_32` for small bases, and `BITS_29_58`, `BITS_30_59`, `BITS_32_58`,
  and `BITS_32_59` for generators with 58 or 59 bits of state.

- `searchGMWC.cpp` does the same for GMWC generators, with modulus
  *m* = *a*₁ *bᵏ* − *a*₀, printing *m*, *e* = −*a*₀, *a*₀⁻¹ mod *b*, and
  *a*₁, with configurations `BITS_32_64`, `BITS_32_128`, `BITS_64_128`, and
  `BITS_64_256` (used in the paper); besides the seed, you can specify the
  maximum number of bits of *e*. The configurations `BITS_8_32` and
  `BITS_16_32` take no argument and enumerate all valid pairs.

- `printdat.cpp` (from [CPRNG](https://github.com/vigna/CPRNG), with
  `common.cpp`) prints configuration files for LatticeTester:

      g++ -O3 printdat.cpp -o printdat -lntl -lgmp

- `searchMWC32.sh FROM TO MAXDIM` and `searchMWC64.sh SEED MAXDIM` run
  `searchMWC` and compute the figures of merit of each candidate up to
  dimension `MAXDIM` for base 2³² and 2⁶⁴, respectively; `searchGMWC32.sh` and
  `searchGMWC64.sh` (`SEED MASKBITS MAXDIM`) do the same for GMWC generators.
  The scripts expect `searchMWC` (or `searchGMWC`) and `printdat` in the
  current directory, and LatticeTester's `lattestZZRR` in the path. They pass
  to `printdat` the base *b* as multiplier, as the figures of merit of *b* and
  of *b*⁻¹ mod *m*, the multiplier of the associated multiplicative
  congruential generator, are the same. For example, the database
  `MWC-64[32]` has been generated by

      ./searchMWC32.sh 0xff000000 0x100000000 8 >"MWC-64[32]"

- `searchMWC29.sh MAXDIM` does the same for the configurations of
  `searchMWC` that take no argument; it passes 2³² as multiplier to
  `printdat`, and expects `lattestZZRR` in the current directory.
